# Lessons waiting to be added

A holding area for general lessons that are not yet ready to become a change to a skill: seen once, or not yet tested.

- Only Part 2 of the lesson template belongs here. Part 1 stays in the project it came from.
- One file per lesson, named for the kind of mistake, for example `status-read-from-an-old-note.md`.
- A file here must pass `bash scripts/check.sh` like everything else.
- When a lesson is added to a skill, delete its file and add a line to the changelog.
- A lesson that has not come up again after a reasonable time is removed.
